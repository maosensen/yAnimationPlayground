# v0.6 Motion Design System

## 核心问题

哪些动作决策已经被现有实验证明，适合在 React 交互与确定性视频之间共享？共享到
什么程度，才不会为了“统一”而抹平不同运行时的优势？

## 对比实现

- `motion-tokens` 只保存毫秒、贝塞尔曲线、弹簧物理值、交错间隔、位移距离、语义
  编排与减少动效策略，不依赖 React 或动画运行时。
- `motion-kit` 把中立 token 适配为 Motion 的 transition、策略 Provider、Reveal、
  Stagger 与 Pressable；每项能力使用独立子路径导出。
- 新的 `/labs/motion-system` 工作台用于切换系统/完整/减少动效策略、重播进入序列，
  并通过快速连续切换验证中断。
- 原有 `/labs/motion` 交互探针改为消费共享策略、Pressable 与 transition，证明原语
  不只服务于新工作台。
- Remotion 作品从同一 token 包读取毫秒与进入曲线，再根据 composition fps 换算为
  帧，证明中立契约可以跨浏览器与视频运行时。

## 契约数据

| 类别 | 规模 | 设计范围 |
|---|---:|---|
| duration | 7 档 | 0–900ms，从即时状态到叙事强调 |
| easing | 5 条 | 线性、标准、进入、退出、强调 |
| spring | 4 组 | 操作反馈、空间布局、柔和变化、表达强调 |
| stagger | 3 档 | 40 / 70 / 110ms |
| distance | 4 档 | 4 / 8 / 16 / 24px |
| choreography | 5 个意图 | feedback、enter、exit、layout、emphasis |

`pnpm test:contracts` 包含 5 组 token 运行时断言，并编译一个覆盖 motion-kit 全部公共
子路径的消费者夹具。它防止时间尺度失序、非法贝塞尔、无效弹簧、悬空语义引用和
跨帧换算漂移。

2026-08-09 的 Next.js 生产构建中，`/labs/motion-system` 相对 `/labs` 总览新增
53,763 B gzip 路由独占 JavaScript：其中 Motion 运行时 chunk 为 44,277 B，工作台
自身为 9,486 B。`/labs` 总览不包含该 Motion chunk，证明策略 Provider 与原语没有
进入全局客户端依赖图。

## 视觉与交互发现

- 在 Codex 内置 Chromium 的桌面视口完成完整目视检查；页头、策略控制、指标卡、
  原语预览、中断探针、token 尺度与规则区层级清楚，无文字遮挡。
- “跟随系统 / 完整动效 / 减少动效”三种策略可即时切换；减少动效状态明确显示
  “位移已降级”，信息与最终值完整保留。
- 连续快速点击“发现 → 聚焦 → 行动 → 发现 → 行动”后，选中状态与内容稳定落在
  “行动 / 建议进入验证”，没有排队播放或失去同步。
- 重播进入序列可重复触发；原有 Motion 交互探针迁移后可连续切换“分群 / 行动”，
  `aria-selected` 与最终内容一致。
- 390 × 844 视口下 `scrollWidth` 与 `innerWidth` 均为 390px，卡片、策略按钮和数值
  网格按单列排列，页面没有横向溢出。
- 新建浏览器会话分别验证工作台与既有 Motion 路由，控制台没有 warning 或 error。
- Remotion 成功打包两种 composition，并使用共享 token 完成 1920 × 1080 横向作品
  的 1080 帧重新渲染。

## 失败模式

- 不把 Motion Provider 放到应用根部。全局挂载虽然省去局部包装，却会让不使用
  动画原语的路由进入同一客户端依赖图。
- 不提供根级 barrel export。按子路径导出能让消费者明确选择策略、过渡或具体原语。
- 不抽象完整时间轴、业务 Tabs 或视频 Scene；这些能力尚未形成第二个同形消费者。
- 不使用多个布尔 prop 组合行为。`preference`、`preset`、`tempo` 与 `feedback` 都是
  有清楚语义的显式变体。

## 技术结论

动作系统应共享“事实与意图”，不共享所有实现。毫秒、曲线、物理参数和无障碍
规则属于公共语言；DOM 布局中断、React Presence 与逐帧插值仍由各自运行时适配。
这样既能统一节奏，也保留 Motion 和 Remotion 的原生调试模型。

## 可复用候选

当前五个 motion-kit 表面已经有工作台与既有交互两类 Web 消费者；中立 token 还有
Remotion 与 CSS 消费者，因此可以稳定在 monorepo 内部。npm 发布、兼容性承诺和跨
仓库升级验证属于 v0.8，不在本版本提前处理。
